# Trip Planner: ระบบวางแผนการเดินทาง
**Capstone Project | Computer Engineering, Suranaree University of Technology**

Trip Planner เป็นโครงงานรวบยอด (Capstone Project) ที่มุ่งเน้นการแก้ปัญหาความยุ่งยากในการวางแผนท่องเที่ยวในกรุงเทพมหานคร โดยเปลี่ยนจากการวางแผนแบบเดิมๆ มาเป็นการใช้เทคโนโลยี AI และอัลกอริทึมทางกราฟที่แม่นยำ

---

## แนวคิดของระบบ (Concept)
โปรเจกต์นี้พัฒนาขึ้นจากแนวคิดที่ว่า **“การจัดทริปไม่ควรเสียเวลา”** ระบบถูกออกแบบมาให้เข้าใจความต้องการของผู้ใช้ผ่านภาษาธรรมชาติ (Natural Language) และคำนวณแผนการเดินทางที่ไม่ใช่แค่ “ไปได้” แต่เป็นแผนที่ **“ไปได้ดีที่สุด”** โดยคำนึงถึงระยะทางและความคุ้มค่าของเวลาในแต่ละวัน

---

## ความสามารถหลัก (Key Features)

* **การโต้ตอบด้วยภาษาธรรมชาติ:** พิมพ์ความต้องการได้เหมือนคุยกับคน เช่น *"มีเวลา 2 วัน อยากเที่ยวคาเฟ่กับวัด งบไม่เกิน 3000"*
* **การสร้างแผนการเดินทางอัตโนมัติ:** จัดกลุ่มสถานที่ท่องเที่ยว ร้านอาหาร และที่พัก พร้อมเรียงลำดับให้อย่างเหมาะสม
* **การคำนวณเส้นทางอย่างมีประสิทธิภาพ:** ใช้อัลกอริทึมเพื่อลดระยะทางรวม หลีกเลี่ยงการเดินทางวน และจัดกลุ่มสถานที่ใกล้เคียง
* **แสดงผลบนแผนที่:** ดูเส้นทางการเดินทางในแต่ละวันบนแผนที่ ช่วยให้เข้าใจภาพรวมได้ง่ายขึ้น
* **ปรับแต่งแผนได้:** ผู้ใช้สามารถเพิ่ม ลบ หรือสลับสถานที่ได้ตามต้องการ โดยมีระบบช่วยแนะนำ (Guidance)
* **Export เป็น PDF:** บันทึกแผนการเดินทางออกมาเป็นไฟล์เพื่อนำไปใช้งานจริงหรือพกพาได้สะดวก

---

## อัลกอริทึมที่ใช้ (Algorithms)

เพื่อให้ได้แผนการเดินทางที่ Optimize ที่สุด ระบบมีการนำอัลกอริทึมทางคอมพิวเตอร์มาประยุกต์ใช้ ดังนี้:

| Algorithm | วัตถุประสงค์การใช้งาน |
| :--- | :--- |
| **K-Nearest Neighbors (KNN)** | ใช้เลือกเฉพาะสถานที่ที่อยู่ใกล้กัน เพื่อลดความซับซ้อนของข้อมูลกราฟ |
| **Prim’s Algorithm** | ใช้สร้างเส้นทางเชื่อมต่อที่ครอบคลุมทุกจุดด้วยระยะทางรวมที่สั้นที่สุด |
| **Dijkstra’s Algorithm** | ใช้ค้นหาเส้นทางที่สั้นที่สุดระหว่างจุดต่อจุด (Point-to-Point) |
| **Boykov-Kolmogorov** | ใช้หลักการ Min-Cut / Max-Flow เพื่อแบ่งโซนการท่องเที่ยว ลดการเดินทางข้ามพื้นที่โดยไม่จำเป็น |

## เทคโนโลยีที่ใช้ (Tech Stack)

* **Frontend:** React + TypeScript
* **Backend:** Go (Gin Framework)
* **Database:** PostgreSQL + PostGIS + pgRouting
* **AI:** Large Language Model (LLM)
* **Tools:** VS Code, pgAdmin, GitHub

---

## จุดเด่นของโปรเจกต์

* **Smart Understanding:** ใช้ AI เพื่อเข้าถึงความต้องการที่แท้จริงของผู้ใช้
* **Route Optimization:** ไม่ใช่แค่การเรียงลำดับ แต่เป็นการคำนวณเพื่อลดการเดินทางที่เหนื่อยเกินไป
* **Practicality:** แสดงผลบนแผนที่จริงและ Export ใช้งานได้ทันที
* **Flexibility:** ระบบทำหน้าที่เป็นผู้ช่วยแนะนำ แต่ยังให้อิสระกับผู้ใช้ในการปรับเปลี่ยนแผน
